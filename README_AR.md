# إدارة الصكوك والعقارات — v0.2.0

تطبيق Desktop محلي مبني بـ React + Vite + Electron مع SQLite. الواجهة عربية RTL والخلفية الأساسية `#E9E4D7`.

## الجديد في v0.2.0
- معاينة بيانات الصك قبل الطباعة ثم طباعة الصك فقط.
- عارض داخلي للصور وملفات PDF مع زر فتح بالبرنامج الافتراضي.
- جدول أكثر وضوحًا: خط أكبر Bold، تغيير عرض الأعمدة بالسحب، إخفاء/إظهار الأعمدة، والتفاف النصوص الطويلة.
- استيراد ذكي من Excel / CSV: اختيار صف العناوين ثم ربط كل حقل بالعمود المناسب واستيراد السجلات دفعة واحدة.
- تخطي رقم الوثيقة المكرر أثناء الاستيراد لتقليل التكرار.
- إعدادات تحديث GitHub: أدخل اسم الحساب واسم Repository، مع فحص تلقائي عند التشغيل وفحص يدوي وتنزيل أحدث Portable EXE.
- أيقونة جديدة مخصصة للتطبيق.
- نفس قاعدة البيانات ومجلد المرفقات السابقين؛ التحديث لا يمسح البيانات.

## تشغيل المشروع
```powershell
npm install
npm run dev
```

## إنشاء النسخة Portable
```powershell
npm run dist:win
```
ستجد الملف داخل مجلد `release`.

## التحديثات
من زر **تحديث**:
1. اكتب حساب GitHub.
2. اكتب اسم Repository.
3. فعّل الفحص التلقائي عند تشغيل البرنامج.
4. اضغط حفظ الإعدادات.
5. اضغط فحص الآن للاختبار.

يجب أن يكون Repository عامًا لكي يعمل الفحص بدون Token، وأن يحتوي أحدث GitHub Release على ملف `.exe`، ويفضل أن يحتوي اسمه على `portable`.

## الاستيراد الذكي
- يدعم `.xlsx` و`.xls` و`.csv`.
- اختر صف العناوين الصحيح.
- اربط على الأقل **رقم الوثيقة** و**اسم المالك**.
- بقية الحقول اختيارية ويمكن ربطها حسب أعمدة ملفك.
- يتم تخطي الصفوف التي ينقصها رقم الوثيقة/اسم المالك، كما يتم تخطي رقم الوثيقة الموجود مسبقًا.

## مكان البيانات
يستخدم التطبيق مجلد Electron `userData/archive-data` ويحتوي على:
- `deeds.sqlite`
- `attachments/`
- `update-settings.json`

لذلك استبدال نسخة البرنامج أو تنزيل إصدار أحدث لا يحذف قاعدة البيانات.
